# 📊 PRD: Sorting Algorithm Visualizer

## 1. 프로젝트 개요 (Project Overview)
사용자가 다양한 정렬 알고리즘(Sorting Algorithms)이 작동하는 과정을 실시간 애니메이션으로 관찰할 수 있는 웹 기반 시각화 도구입니다. 복합적인 알고리즘 로직을 직관적인 막대 그래프와 색상 변화로 표현하여 시각적 이해를 돕습니다.

## 2. 주요 기능 (Core Features)
### 2.1 데이터 제어
* **랜덤 배열 생성:** 버튼 클릭 시 무작위 높이를 가진 막대 그래프 배열 생성.
* **배열 크기 조절:** 슬라이더를 통해 정렬할 데이터의 개수(막대 개수) 설정.

### 2.2 알고리즘 시각화
* **알고리즘 선택:** 버블 정렬, 선택 정렬, 삽입 정렬, 퀵 정렬, 병합 정렬 중 선택.
* **실시간 애니메이션:** 데이터 비교 및 스왑(Swap) 과정을 애니메이션으로 노출.
* **상태별 색상 피드백:** * 기본 상태: 파란색
    * 비교 중: 빨간색
    * 위치 변경/스왑: 노란색
    * 정렬 완료: 초록색

### 2.3 실행 제어
* **속도 조절:** 시각화 애니메이션의 실행 속도를 실시간으로 변경.
* **시작/초기화:** 정렬 실행 및 초기 상태로 되돌리기.

## 3. 기술 스택 (Technical Stack)
* **Framework:** React.js (또는 Next.js)
* **Styling:** Tailwind CSS
* **State Management:** React Hooks (useState, useEffect, useRef)
* **Deployment:** Vercel 또는 GitHub Pages

## 4. 사용자 인터페이스(UI) 설계
* **Top Navigation:** * 로고 및 프로젝트 타이틀.
    * 알고리즘 선택 드롭다운 메뉴.
    * 배열 크기 및 애니메이션 속도 조절 슬라이더.
* **Main Visualizer Area:** * 중앙에 위치한 정렬 막대 그래프 영역.
    * 배열 크기에 따라 막대 너비가 유동적으로 변하는 반응형 디자인.
* **Control Bar:** * '새 배열 생성', '정렬 시작' 버튼 배치.

## 5. 단계별 개발 로드맵 (Roadmap)
* **Phase 1: UI 뼈대 구축** - Tailwind를 이용한 레이아웃 설계 및 랜덤 막대 생성 로직 구현.
* **Phase 2: 핵심 유틸리티** - 애니메이션 지연을 위한 `sleep` 함수 및 비동기 처리 구조 설계.
* **Phase 3: 기본 알고리즘** - 버블 정렬, 선택 정렬 시각화 완성.
* **Phase 4: 고급 알고리즘** - 재귀를 사용하는 퀵 정렬, 병합 정렬 시각화 및 최적화.
* **Phase 5: 마무리** - 다크모드 지원 및 알고리즘별 시간/공간 복잡도 정보 표시.

## 6. 성공 지표 (Success Metrics)
* 사용자가 정렬 과정을 끊김 없이(Smoothly) 관찰할 수 있는가?
* 알고리즘이 진행됨에 따라 막대의 색상이 논리적으로 변하는가?
* 다양한 화면 크기(반응형)에서 막대 그래프가 깨지지 않고 출력되는가?
