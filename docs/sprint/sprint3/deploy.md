## 수동 검증 필요 항목

### 색상 피드백 시각적 확인 (브라우저에서 직접 확인 필요)

> `npm run dev` 실행 후 `http://localhost:3000` 접속

- ⬜ **버블 정렬 색상 피드백 확인**
  - 인접 요소 비교 시 두 막대가 빨간색(bg-red-500)으로 변경
  - 스왑 발생 시 두 막대가 노란색(bg-yellow-400)으로 변경
  - 각 패스 완료 시 마지막 요소부터 초록색(bg-green-500)으로 변경
  - 정렬 완료 후 모든 막대가 초록색으로 웨이브 애니메이션

- ⬜ **선택 정렬 색상 피드백 확인**
  - 탐색 중인 요소: 빨간색
  - 현재 최솟값 후보: 노란색 유지 (더 작은 값 발견 시 이동)
  - 정렬 확정 위치: 초록색

- ⬜ **삽입 정렬 색상 피드백 확인**
  - 삽입할 키(key) 요소: 빨간색
  - 이동(shift) 중인 요소: 노란색
  - 확정된 정렬 구간: 초록색으로 순차 확장

### 실시간 속도 조절 검증

- ⬜ 정렬 진행 중 속도 슬라이더를 최저속(1) → 최고속(10)으로 변경 시 즉시 반영 확인
