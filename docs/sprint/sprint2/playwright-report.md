## 수동 검증 필요 시나리오

### 시나리오 1: 색상 상태 변화 검증 (더미 버블 정렬)

1. `http://localhost:3000` 접속
2. "새 배열 생성" 버튼 클릭 → 모든 막대가 파란색(기본) 상태인지 확인
3. "정렬 시작" 버튼 클릭
4. 비교 중인 두 막대가 빨간색으로 변경되는지 확인
5. 교환 시 노란색으로 변경되는지 확인
6. 정렬 완료 후 모든 막대가 초록색 웨이브 애니메이션으로 전환되는지 확인
7. 브라우저 콘솔 에러 없음 확인 (F12 → Console)

### 시나리오 2: 실행 제어 검증

1. "새 배열 생성" 버튼 클릭
2. "정렬 시작" 버튼 클릭
3. 정렬 중 버튼 상태 확인:
   - "새 배열 생성" 버튼이 비활성화(회색, 클릭 불가)인지 확인
   - "정렬 시작" 버튼이 비활성화이고 "정렬 중..." 텍스트로 변경되었는지 확인
   - 알고리즘 드롭다운이 비활성화인지 확인
   - 배열 크기 슬라이더가 비활성화인지 확인
4. 정렬 중 "초기화" 버튼 클릭
5. 정렬이 즉시 중단되고 새 배열로 초기화되는지 확인

### 시나리오 3: 속도 슬라이더 실시간 연동 검증

1. 속도 슬라이더를 최저속(1)으로 설정
2. "정렬 시작" 버튼 클릭 → 애니메이션이 느리게 진행되는지 확인
3. 정렬 진행 중 속도 슬라이더를 최고속(10)으로 변경
4. 다음 스텝부터 속도가 즉시 빨라지는지 확인
