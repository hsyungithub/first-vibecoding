## 수동 검증 필요 항목

### UI 기능 검증 (npm run dev 실행 후 브라우저에서 직접 확인)

> 실행 명령어: `npm run dev` (프로젝트 루트에서)

#### 색상 상태 변화 검증

- ⬜ "정렬 시작" 클릭 시 비교 중인 두 막대가 빨간색(`bg-red-500`)으로 변경됨
- ⬜ 교환 발생 시 두 막대가 노란색(`bg-yellow-400`)으로 변경됨
- ⬜ 정렬 완료 후 왼→오 순서로 초록색(`bg-green-500`) 웨이브 애니메이션 실행됨
- ⬜ 브라우저 콘솔(F12 → Console)에 에러/경고 없음

#### 정렬 실행 제어 검증

- ⬜ 정렬 중 "새 배열 생성" 버튼이 비활성화(disabled)됨
- ⬜ 정렬 중 "정렬 시작" 버튼이 비활성화되고 "정렬 중..." 텍스트 표시됨
- ⬜ 정렬 중 알고리즘 드롭다운이 비활성화됨
- ⬜ 정렬 중 배열 크기 슬라이더가 비활성화됨
- ⬜ 정렬 중 속도 슬라이더는 조작 가능함 (항상 활성화 상태)
- ⬜ "초기화" 버튼 클릭 시 정렬이 즉시 중단되고 새 배열로 초기화됨

#### 속도 슬라이더 실시간 연동 검증

- ⬜ 속도 슬라이더를 최저속(1)으로 설정 후 정렬 시작 시 애니메이션이 느리게 진행됨
- ⬜ 정렬 진행 중 속도 슬라이더 변경 시 다음 스텝부터 즉시 반영됨

### 시각적 디자인 확인

- ⬜ 비교(빨간) → 교환(노란) → 기본(파란) 색상 전환이 자연스럽게 보임
- ⬜ 완료 웨이브 애니메이션이 시각적으로 매력적임 (왼쪽 → 오른쪽 순차 초록)
- ⬜ 비활성화된 UI 요소가 시각적으로 구분됨 (불투명도 낮아짐)

### 배포 (타이밍은 사용자가 결정)

  - main 브랜치 머지 후 자동 배포 확인
